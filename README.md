# ✨ Random Quote Generator

A simple and responsive Random Quote Generator built using HTML5, CSS3, and JavaScript.

The application displays a random quote and its author whenever the user clicks the **New Quote** button.

## 🎯 Objective

The objective of this project is to practice:

- JavaScript arrays
- Objects
- Random number generation
- Event handling
- DOM manipulation
- Basic responsive web design

## 🚀 Features

- Displays a random quote and author
- Contains 10+ quotes stored in JavaScript
- Generates a new quote using `Math.random()`
- Prevents the same quote from appearing twice consecutively
- Responsive design for different screen sizes
- Share Quote button
- Clean and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
